MCP Tools

What are MCP Tools?
MCP (Model Context Protocol) tools let AI models interact with MarketHub — querying live market data, managing alerts, and computing analytics. Tools are invoked automatically by the AI during chat conversations, or can be called via the MCP protocol directly.

How it works: The AI reads tool descriptions and schemas to decide which tool to call and with what parameters. You approve each tool call before execution. Results are returned as structured data the AI can reason over.

Categories: Market (quotes, depth, search) · Alerts (create, list, enable/disable) · Condition Alerts (trigger-based alerts) · Compute (PCR, max pain, IV skew, support/resistance) · Pricing (straddle, strangle, spreads, iron condor) · Events (publish, list) · Consumer (register, topics, ACK) · System (ping)
